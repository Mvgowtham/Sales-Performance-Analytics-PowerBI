# 📊 Sales Performance Analytics Dashboard (Power BI)

## 📌 Project Overview
This project presents an interactive **Sales Performance Analytics Dashboard** built in Power BI to analyze overall business revenue, profitability, regional distribution, and product category trends using the Superstore dataset.

## 🔑 Key Features & Insights
* **KPI Header Cards**: Real-time tracking of Total Sales ($13M), Total Profit ($1M), Profit Margin % (12%), and Total Orders (51K).
* **Time Intelligence & Sales Trends**: Line chart evaluating YoY sales performance across months (`Total Sales` vs `PY Sales`).
* **Category Performance**: Visualizing profitability and sales distribution across Technology, Furniture, and Office Supplies.
* **Regional Breakdown**: Donut chart detailing sales spread across different global regions.
* **Interactive Slicers**: Dynamic filtering by `Year` and `Region`.

## 🛠️ Data Modeling & Tech Stack
* **Tool**: Power BI Desktop
* **Data Schema**: Star Schema (1 Fact Table, 4 Dimension Tables)
* **ETL & Data Prep**: Power Query Editor (Data Cleaning, Unpivoting, Type Corrections)
* **DAX Calculations**: Created 10+ core measures including Time Intelligence, YoY Growth %, Profit Margin %, and AOV.
